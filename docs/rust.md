# Rust API

The core is a normal Rust crate — `crate-type = ["cdylib", "rlib"]` — so it is
usable directly from Rust, not only through the WebAssembly bindings. These pages
are generated by `cargo doc` from the `///` comments in `rust/`.

## Where to start

| Item | What it covers |
| --- | --- |
| `write_shapefile` | GeoJSON to `.shp`/`.shx`/`.dbf` bytes |
| `read_shapefile` | Those bytes back to GeoJSON |
| `schema` | `.dbf` column inference and field naming |
| `geometry` | GeoJSON to the concrete shapefile shape types |
| `read` | Ring re-nesting, winding, and `.dbf` encodings |
| `error` | Every failure mode, with the feature index where one applies |

The crate deliberately knows nothing about zip files, projections or browsers.
It converts between GeoJSON and shapefile bytes and stops there — see
[Architecture](/guide/architecture) for why.
